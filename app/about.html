Prompt Builder Edition

Aurora Forge v1.7 Major RC1

A portable WWE 2K26 prompt-building and workflow-preparation workspace. Guided builders turn project choices into detailed prompts and supporting handoff packs. The user then chooses a compatible AI or image tool to create the result.

Aurora Forge builds the instructions. It does not chat with the user or generate the finished creative artwork.

Important boundaries
  • Aurora Forge is not affiliated with or endorsed by WWE, 2K, Visual Concepts, CakeView, CakeHook, Tribute, or the maintainers of third-party modding tools.
  • No extracted WWE model, texture, audio, or archive assets are bundled with Aurora Forge.
  • Setup does not download or install third-party programs. Users choose software and paths they are authorized to use.
  • Character Viewer is an approximate local preview. It does not reproduce the game renderer and does not write to proprietary files.
  • Back up original files, follow current tool documentation, respect licenses and permissions, and perform final validation in game.
